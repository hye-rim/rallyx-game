# 방구차 🚗

추억의 오락실 게임 「방구차」(원작 이름 New Rally-X 에 가깝게 만든 혼자 하기). [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. 서버 없이 `index.html` + `logic.js`(규칙) + `game.js`(화면·입력·소리)로 돌아갑니다. 그림은 모두 코드로 그린 것이다(원작 그림·소리는 쓰지 않았다).

- **미로**: 18x18 갈림길(칸으로는 55x55)을 깊이 우선으로 만들고 일부 벽을 터서 돌아갈 길을 낸다. 라운드마다 다른 미로(시드 3종을 돌려 쓰다 100씩 더해 계속 바뀜). 화면은 14x15칸이 내 차를 따라 스크롤된다
- **내 차**(파란 차): **혼자 계속 달린다.** 방향키/WASD 로 가고 싶은 방향을 정하면 다음 갈림길에서 꺾고, 길 한가운데서는 U턴만 된다. 막다른 곳이나 벽 앞에서는 선다. 폰은 왼쪽 방향 패드(누른 채 끌면 방향이 바뀜)
- **연막(방구)**: 스페이스(Z·X·J) 또는 폰의 연막 버튼을 **누르고 있으면** 차 뒤로 연막이 나간다(서 있어도 나간다). 연료가 줄고, 연막에 닿은 빨간 차는 2.6초 멈추며 80점
- **연료**: 계속 줄고(약 90초) 연막을 뿜으면 더 줄어든다. 바닥나면 속도가 반으로 줄고 연막을 못 쓴다. 라운드가 끝나면 다시 가득 찬다
- **깃발**: 라운드마다 10개(노란 깃발). 첫 깃발은 시작 지점에서 5~9걸음 가까이에 있다. **연달아 먹으면 100 · 200 · 300 … 1000점**(차가 부서지면 처음부터 다시). 빨간 **S 깃발**은 한 라운드에 한 개(첫 깃발 제외)이고, 먹으면 그 뒤로 받는 깃발 점수가 두 배. 10개를 다 먹으면 라운드 클리어, 남은 연료 × 10점
- **빨간 차**: 라운드 1에 2대, 3라운드마다 한 대씩(최대 5). 레이더의 최단 길을 따라 쫓아오고(차마다 따라오는 정도가 달라 한곳에 뭉치지 않음), 속도는 내 차의 약 71%에서 라운드마다 빨라져 최대 90%(내 차보다 항상 느림). 닿으면 내 차가 부서진다(멈춘 빨간 차는 안전). 바위에 걸리면 3.2초 멈추며 50점
- **바위**: 라운드마다 16개(보너스 라운드는 6개). 내 차가 닿으면 부서진다. 모든 깃발에 바위를 피해서 갈 수 있는 길이 항상 있다
- **보너스 라운드**: 4라운드마다. 빨간 차가 없고 연막을 못 쓰며 연료가 1.4배 빨리 줄고 깃발이 두 배 점수
- **목숨**: 3개, 2만 점에서 하나, 6만 점 이후 4만 점마다 하나. 부서지면 시작 지점에서 2초 동안 안전한 채로 다시 나오고, 먹은 깃발은 그대로
- **레이더**: 오른쪽에 전체 지도와 깃발(노랑, S 는 빨강), 빨간 차, 내 차(깜빡임)
- **일시정지**: 창을 벗어나거나 탭이 가려지면 저절로 멈춘다 (P 로도). 최고 점수는 `rallyxBest`

원작과 다르게 정했거나 기억에 의존한 점: 맵 모양, 연료·연막·깃발 점수의 정확한 수치, 빨간 차 수와 속도, 보너스 라운드의 규칙, 바위에 닿으면 내 차가 부서진다는 것, 행운 깃발(원작에 있었는지 확실하지 않아 넣지 않음).

시험은 `node --test`(`test/logic.test.js`): 미로 모양과 고리 · 깃발과 바위 배치(깃발까지 길이 있는지) · 빨간 차 수 · 자동 주행과 꺾기와 U턴 · 깃발 점수와 S 깃발 · 라운드 클리어와 연료 보너스 · 보너스 라운드 · 연료와 연막 · 빨간 차 멈춤 · 목숨과 보호 시간 · 추격 · 무작위 플레이.

튜토리얼 신호(`arcade/tutorials.js`): `steer`(방향을 정함) · `flag`(깃발을 먹음) · `smoke`(연막을 뿜음) · `stun`(빨간 차를 멈춤).
